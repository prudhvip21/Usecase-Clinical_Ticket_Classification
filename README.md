# Clinical Ticket Classification

Route healthcare call tickets to the right category and subcategory automatically, using free text written by many staff members with no standard format.

## Approach

- Text preprocessing and spell correction for noisy clinical text
- TF-IDF and CountVectorizer features
- Classification with Naive Bayes, SVM, Logistic Regression and Random Forest across 20 subcategories

## Results

Accuracy between about 0.59 and 0.74 in the saved notebook output.
